## LSDCXX_WeaponWheelVC — 修复「弹药耗尽武器仍留在玩家身上」+ 加入手柄支持

改动文件：`source/LSDCXX_WeaponWheelVC.cpp`、`LSDCXX_WeaponWheelVC.ini`、`README.md`

### 1. 弹药耗尽后武器仍留在玩家身上（bug）
根因：`CollectSlots()` 用 `(type != UNARMED && type <= ANYWEAPON)` 判定"持有武器"，
完全不看弹药；`ApplySelectedWeapon()` 又会把选中的槽位强行 `SetCurrentWeapon`。
于是打空的枪仍出现在轮盘里、仍可被选中装备，然后一直挂在玩家身上。

修复：
- 新增 `IsMeleeWeaponType`(1~11)、`IsSpecialToolType`(34 引爆器 / 36 相机)、
  `WeaponHasAmmo`(total>0 || clip>0)、`IsSlotUsable`。
- `CollectSlots()`：只有近战 / 特殊道具 / 还有弹药的槽位才算持有；打空的枪按空槽处理。
- `ApplySelectedWeapon()`：`!sel.hasWeapon` 或目标槽位不可用时直接 return，不再强装。
- 新增 `RemoveDepletedWeapons()`（INI `RemoveDepletedWeapons`，默认 1）：
  每帧扫描 10 个槽位，把弹药为 0 的枪械真正清空（type→UNARMED），
  若清的是当前武器则自动切到剩余最强的武器（找不到就空手）并调用
  `SetCurrentWeapon` + `MakeChangesForNewWeapon` 刷新模型，让枪真正从手上消失。
- 顺带同步 `m_nSelectedWepSlot`，避免游戏立刻切回去。

### 2. 手柄支持（GInput）
- 接入 `third_party/GInputAPI/GInputAPI.h`（`#define GINPUT_COMPILE_VC_VERSION`），
  通过 `GInput_Load` + `GINPUT_EVENT_FETCH_PAD_SETTINGS` 读取当前 Control Set，
  并注册 `GINPUT_EVENT_REGISTER_SETTINGS_RELOAD_CALLBACK` 在 GInput ini 重载时刷新。
- 呼出轮盘按键：Control Set 1（PS2 VC 风格）→ **L2**（LeftShoulder2）；
  Set 5（GTA IV 风格）→ **十字键左**（DPadLeft）；其它/未检测到 → 两者都接受。
- 换武器：**右摇杆**直接做方向选择（绝对量，带死区 `GamepadDeadzone`，默认 0.25），
  另外十字键上/下可逐格切换（`GamepadDPadStep`，默认 1）。
- `SuppressCombatInput()` 补充屏蔽 L2/R2、十字键上下、右摇杆，防止开轮盘时相机漂移。
- 内部瞄准向量约定：`gAimY < 0` 表示朝上（与鼠标管线 `my = -mouse.y` 一致），
  所以摇杆 `gPadAimY = -(RightStickY/128)`；提供 `GamepadInvertVertical` 兜底反转。
